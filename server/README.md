# Mafia Game Server

Production-ready Node.js backend for the Mafia multiplayer game.

## Stack

- **Runtime**: Node.js 20+
- **Web framework**: Express 4
- **Real-time**: Socket.IO 4
- **Database**: SQLite (via Prisma ORM — portable to PostgreSQL)
- **Auth**: Firebase Admin SDK (verifies client JWTs)
- **Validation**: Zod

## Project layout

```
server/
├─ prisma/
│  ├─ schema.prisma    # Data model (SQLite, portable to Postgres)
│  └─ migrations/      # Generated by `npm run db:migrate`
├─ src/
│  ├─ index.ts         # Express + Socket.IO entrypoint
│  └─ game/
│     └─ logic.ts      # Role assignment, phase resolution, win check
└─ package.json
```

## Getting started

```bash
cd server
cp ../.env.example .env           # also add DATABASE_URL="file:./dev.db"
npm install
npm run db:migrate                # creates SQLite + tables
npm run db:seed                   # optional sample data
npm run dev                       # tsx watch src/index.ts (port 3001)
```

## API

### REST

| Method | Path                       | Description                       |
|--------|----------------------------|-----------------------------------|
| GET    | `/api/health`              | Health check                      |
| GET    | `/api/leaderboard`         | Top 100 players by points         |
| GET    | `/api/profile/:uid`        | Full profile + match history      |
| GET    | `/api/rooms`               | Public waiting rooms              |
| POST   | `/api/rooms`               | Create room (auth required)       |

All authenticated endpoints expect `Authorization: Bearer <firebase-id-token>`.

### Socket.IO events

Connect with `auth: { token: <firebase-id-token> }`.

**Client → Server**
- `room:join { code, password? }`
- `room:leave`
- `room:start`
- `room:kick { targetUid }`
- `chat:message { message }`
- `game:action { type: "kill" | "save" | "investigate", targetUid }`
- `game:vote { targetUid }`

**Server → Client**
- `room:state` — full room snapshot (role masked for others)
- `room:player-joined` / `room:player-left`
- `chat:message { uid, username, message, type, timestamp }`
- `game:phase { phase, round, timer }`
- `game:role-reveal { role }` (private)
- `game:police-result { isMafia }` (private)
- `game:announcement { message }`
- `game:vote-update { votes: { [uid]: count } }`
- `game:over { winner, players }`
- `error { message }`

## Migrating to PostgreSQL

1. Change `datasource db { provider = "postgresql" url = env("DATABASE_URL") }` in `schema.prisma`.
2. Set `DATABASE_URL="postgresql://user:pass@host:5432/mafia"`.
3. `npm run db:migrate` — Prisma generates Postgres-compatible SQL automatically.

No application code changes required.

## Security

- All REST mutations require verified Firebase JWT.
- Socket connections rejected without valid token.
- Role information is only sent to the player who holds it.
- Dead players cannot send chat, vote, or use abilities.
- Mafia chat is only routed to alive mafia members.
- Server is authoritative: client actions are validated and can be rejected.
